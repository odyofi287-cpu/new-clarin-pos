# New Clarin Sports Arena POS

This folder contains the initial scaffold for the New Clarin Sports Arena web-based POS system.

## Stack
- Backend: Node.js + Express + SQLite
- Frontend: React + Vite

## Next steps
1. Install backend dependencies: `cd new-clarin-pos/server && npm install`
2. Install frontend dependencies: `cd new-clarin-pos/client && npm install`
3. Start the backend: `npm run dev`
4. Start the frontend: `npm run dev`

## Project scope
The initial scaffold includes:
- Authentication-ready backend structure
- Inventory/sales/delivery database schema
- React/Vite frontend skeleton
- Health check and API scaffolding
